# Рассвет Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Собрать веб-игру «Рассвет» — 2D выживание вид сверху, 5 минут до рассвета.

**Architecture:** Классические `<script>` теги, общий глобальный объект `Rassvet`. Чистая логика (`config.js`, `upgrades.js`, `Spawner.js`) не зависит от Phaser и тестируется в Node. Сцены Phaser связываются событиями `GameScene.events`.

**Tech Stack:** Phaser 3.90.0 (CDN jsDelivr), Arcade Physics, Node (только для тестов логики), без сборки.

**Spec:** `docs/superpowers/specs/2026-10-09-rassvet-design.md`

## Global Constraints

- Phaser `3.90.0` с `https://cdn.jsdelivr.net/npm/phaser@3.90.0/dist/phaser.min.js`.
- Без сборщика, без npm-зависимостей игры, без ES-модулей: открывается двойным кликом по `index.html`.
- Размер игры 1280×720, `Scale.FIT`; мир 2000×1500; костёр в центре мира.
- `NIGHT_SECONDS = 300`; при `?debug` в адресе — `30`. Все кривые считаются от доли ночи `f = t / NIGHT_SECONDS`.
- Файлы логики (`config.js`, `upgrades.js`, `Spawner.js`) пишутся так, чтобы грузились и в браузере, и в Node: `const R = (globalThis.Rassvet = globalThis.Rassvet || {});`.
- Графика только кодом (canvas-текстуры в `src/art/textures.js`), звука нет.
- Лучшее время: `localStorage` ключ `rassvet.best`, чтение и запись в `try/catch`.
- Игрок: HP 120, скорость 200, 5 выстрелов/с, урон 12, скорость пули 600, жизнь пули 1000 мс, пробивание 0, пуль 1, радиус подбора 100.
- Враги: ходок HP 20 / скорость 70 / урон 8 / опыт 1; бегун 10 / 130 / 5 / 1; громила 80 / 45 / 15 / 4. Кулдаун урона от одного врага 0.8 с. Макс. 80 живых. HP × `(1 + 0.3 * f)`.
- Спавн: `spawnPerSec(f) = 0.6 + 1.6 * f`; `f<0.15` ходоки; `0.15≤f<0.4` ходоки:бегуны 3:1; `f≥0.4` 5:3:1 (ходок:бегун:громила).
- Опыт до уровня: `4 + 2 * (level - 1)`.
- Улучшения (id, макс): `fireRate` 5 (+20%), `damage` 5 (+25%), `speed` 4 (+10%), `maxHp` 4 (+25 макс. HP и лечение 25), `multishot` 3 (+1 пуля, веер 12°), `pierce` 3 (+1).
- Костёр: радиус 120, лечит 5 HP/с.
- Текст интерфейса на русском.
- Репозиторий не git: шаги коммита опущены.
