# Текст для страницы на itch.io

**Название:** Рассвет

**Короткое описание (до 100 символов):** Продержись одну ночь у костра: монстры, боссы, дрон и огненное кольцо.

**Жанр:** Action. **Теги:** survival, top-down, shooter, 2d, browser, singleplayer, boss-fight, roguelite, phaser.

**Язык:** русский. **Платформа:** HTML5 (играть в браузере, только компьютер).

## Описание

Наступила ночь. Ты один у костра, а из темноты идут монстры. Продержись пять минут до рассвета: солнце сожжёт всех тварей.

- Стреляй в монстров, собирай кристаллы опыта и выбирай улучшения на каждом уровне.
- Рывок на Shift делает неуязвимым на миг, огненное кольцо на Q отбрасывает и поджигает всех вокруг.
- Ломай ящики: из них падают лечение, магнит, оружие на 25 секунд (дробовик, лазер, ракетница) и капсула защиты.
- Летающий дрон-помощник стреляет сам, до трёх дронов.
- Туман, кровавая луна и ливень меняют ночь: монстров больше, но и опыта больше.
- Четыре волны боссов: Демон, Каменный колосс, Призрак. У каждого свои атаки с предупреждением на земле.
- С боссов падают алмазы. В магазине за них покупаются улучшения навсегда: здоровье, урон, скорость, рывок и другое.

## Управление

| | |
|---|---|
| WASD / стрелки | идти |
| Мышь | целиться, зажатая кнопка стреляет |
| Пробел | авто-огонь вкл/выкл (открывается на 5 уровне) |
| Shift | рывок |
| Q | огненное кольцо |
| E | капсула защиты |
| Esc / P | пауза |

## Настройки на itch.io

- Kind of project: HTML, архив `rassvet-<версия>.zip`, отметить «This file will be played in the browser».
- Viewport: 1280 × 720, включить Fullscreen button, мобильные устройства не поддерживаются.
- Скриншоты: меню, игра с монстрами, бой с боссом, магазин (сделай в игре сам, 1280 × 720 или крупнее).
- Обложка: 630 × 500. Можно взять скриншот костра с монстрами вокруг.
