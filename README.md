# Рассвет

2D игра на выживание в браузере. Ночь, костёр, монстры со всех сторон. Продержись 5 минут до рассвета: стреляй, прокачивайся, ломай ящики, побеждай боссов и копи алмазы на постоянные улучшения.

Движок: [Phaser](https://phaser.io) 3.90.0. Вся графика нарисована кодом, внешних картинок нет. Звука пока нет.

## Как играть

| Действие | Клавиши |
|---|---|
| Идти | `W` `A` `S` `D` или стрелки |
| Целиться | мышь |
| Стрелять | зажатая кнопка мыши (с 5 уровня включается авто-огонь, `Пробел` — вкл/выкл) |
| Рывок (на миг неуязвим) | `Shift` |
| Огненное кольцо | `Q` (перезарядка 18 с) |
| Капсула защиты | `E` (если нашёл в ящике) |
| Пауза | `Esc` или `P`, либо кнопка в углу |

Цель: дожить до рассвета. Монстры роняют кристаллы опыта, на новом уровне выбираешь улучшение. С боссов падают алмазы: их можно потратить в магазине на улучшения, которые остаются навсегда. Подробные правила: [docs/superpowers/specs/2026-10-09-rassvet-design.md](docs/superpowers/specs/2026-10-09-rassvet-design.md).

Нужен компьютер с клавиатурой и мышью и современный браузер (Chrome, Edge, Firefox, Safari) с WebGL. На телефоне игра покажет предупреждение.

## Запуск

Открой `index.html` двойным кликом. Phaser лежит в `vendor/`, интернет не нужен, сервер не нужен.

Прогресс (лучшее время, алмазы, покупки в магазине) хранится в браузере (`localStorage`, ключи `rassvet.*`). Сбросить всё: в консоли страницы `localStorage.clear()`.

## Разработка

```bash
npm test          # тесты логики (node tests/logic.test.js)
npm run build     # проверки + тесты + сборка в dist/
npm run release   # то же + архив rassvet-<версия>.zip
```

Node нужен только для тестов и сборки. Зависимостей нет (`npm install` не нужен).

Режим отладки: добавь к адресу `?debug`. Ночь длится 30 секунд вместо 5 минут, прогресс и рекорды не сохраняются. Страница `index.html` при этом читает исходники из `src/`; в сборке они упаковываются в один `game.js`.

Структура:

```
index.html          страница игры (в ней список скриптов между маркерами scripts:begin/end)
src/
  config.js         константы баланса, версия, сохранения
  systems/          правила без Phaser (появление монстров, оружие, события, магазин, рывок...)
  entities/         игрок, монстры, дрон, капсула
  scenes/           меню, игра, интерфейс, конец игры, магазин
  art/textures.js   вся графика, нарисованная кодом
vendor/             Phaser (см. THIRD_PARTY.md)
tests/              тесты логики
tools/build.js      сборка и проверки перед выпуском
docs/               спецификация и план
```

## Выпуск на itch.io

1. Подними версию в `package.json` и `src/config.js` (они должны совпадать, сборка проверит), допиши `CHANGELOG.md`.
2. `npm run release`. Появится `rassvet-<версия>.zip` (внутри `index.html` в корне архива).
3. На itch.io: *Create new project*, *Kind of project*: **HTML**. Загрузи zip и отметь *This file will be played in the browser*.
4. *Embed options*: размер окна **1280 × 720**, включи **Fullscreen button**. Мобильные устройства не поддерживаются.
5. Текст страницы, теги и описание готовы в [docs/itch-page.md](docs/itch-page.md).
6. Перед публикацией открой страницу в режиме *Draft* (кнопка *View page*) и пройди игру до конца.
